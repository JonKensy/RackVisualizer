LLDP collection

When enabled, hovering a server queries its iDRAC for NIC-to-switch LLDP connectivity (one Redfish walk per host, cached 60 seconds). Turn this off if you do not need the connectivity data — no iDRAC LLDP requests are then made.

Switch MAC to Name

LLDP tooltips show the friendly name when the switch chassis MAC reported by the iDRAC matches an entry here. Any common MAC notation (colons, dashes, dots, or bare hex) is accepted and normalized.
