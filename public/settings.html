iDRAC credentials

Used to query the hosts in servers.json and manually added nodes. Stored encrypted (AES-256-GCM, key in data/.enc_key). Leave the password blank to keep the stored one. These values override the IDRAC_USER/IDRAC_PASSWORD environment variables.

LLDP collection

When enabled, hovering a server queries its iDRAC for NIC-to-switch LLDP connectivity (one Redfish walk per host, cached 60 seconds). Turn this off if you do not need the connectivity data — no iDRAC LLDP requests are then made.

Discover iDRAC from PowerFlex

When enabled, the rack view shows only PowerFlex-discovered iDRAC nodes plus manually added switches; servers.json and manually added nodes are ignored until the toggle is turned off.

Switch MAC to Name

LLDP tooltips show the friendly name when the switch chassis MAC reported by the iDRAC matches an entry here. Any common MAC notation (colons, dashes, dots, or bare hex) is accepted and normalized. The last two octets are ignored when matching — switches encode the port number in them, so enter any values there (e.g. :00:00) and the entry matches every port on that switch.
